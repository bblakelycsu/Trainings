Transforms Argos section enrollment data and Brightspace analytics into a formatted LiveText-ready import spreadsheet for Chicago State University.

📝 Instructions

  1. Upload File 1 — the Section Enrollment Report from Argos (CSV) with only the selected classes added. Remove any extra courses before uploading.
  2. Upload File 2 — the Brightspace Analytics export (XLSX) with the courses also filtered down. Only rows with LIS or TPS in the CourseName will be used for matching.
  3. Click Convert & Generate. Only LIS and TPS subject courses will be included. Canceled classes (STAT = C) are automatically removed.
  4. Preview the results and download your new LiveText-ready spreadsheet.
