Converts Argos Section Enrollment Reports into ExamSoft-ready import files for Course Management and Brightspace course sync integration.

ExamSoft Brightspace Sync

ℹ️ Instructions

  1. Export the Section Enrollment Report from Argos as a .csv file.
  2. Upload the file below. The converter will filter to include only Pharmacy (PHAR) courses that have not been cancelled, have credit hours greater than 0, and exclude APPE- titled courses.
  3. Two files will be generated:
  4. courses.txt.xlsx — Upload this to ExamSoft Course Management to import the new classes for the semester.
  5. course_sync.csv — Add this to the Course Import Tool within Brightspace to sync the ExamSoft and Brightspace connection.
