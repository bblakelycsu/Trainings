Student Roster LiveText Converter

Converts Brightspace Analytics student enrollment data into a formatted LiveText student roster import spreadsheet (.xlsx) for Chicago State University courses.

📝 Instructions

  1. Pull the student enrollment file from Brightspace Analytics using the Section Enrollment report filtered per course. This file needs to be pulled from each course individually.
  2. Upload the exported .xlsx file below. The tool expects the Brightspace Analytics format with headers on row 3.
  3. Click Convert & Generate. The tool will extract student data and format it for LiveText import.
  4. Preview the results and download your new student roster spreadsheet.
🔒 No data is stored — all processing happens locally in your browser
